# Data Directories

This directory contains all data used and generated by the Space Debris Risk Prediction pipeline.

## Structure

### raw/
Contains raw, unprocessed data from external sources:
- Space debris catalogs
- Satellite catalogs
- Original TLE (Two-Line Element) data from Space-Track API

### processed/
Contains processed and transformed data:
- TLE_History/ - Historical TLE data organized by satellite ID
- TLE_History_Satellites/ - Satellite-specific TLE histories
- Computed orbital positions from SGP4 propagation

### external/
Contains external dependencies and reference data:
- de421.bsp - JPL planetary ephemeris file
- Other astronomical reference data

### archive/
Long-term storage for historical data and backups:
- Archived datasets
- Historical snapshots
- Backup copies

## Data Management

- Raw data should remain immutable once ingested
- Processed data can be regenerated from raw data + pipeline code
- External dependencies are version-controlled
- Archive data follows retention policies (document your policy here)

## Size Considerations

This is a big data project - expect directories to grow significantly:
- TLE histories can contain millions of records
- Processed orbital predictions are stored in Parquet format for efficiency
- Use HDFS for very large datasets that exceed local storage

## Gitignore

Most data directories are gitignored to avoid committing large datasets:
- `data/raw/*` - Ignored (except .gitkeep)
- `data/processed/*` - Ignored (except .gitkeep)
- `data/archive/*` - Ignored (except .gitkeep)
- `data/external/` - Tracked (small reference files)
